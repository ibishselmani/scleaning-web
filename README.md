# SCleaning Web

Browser manager for the SCleaning cleaning-reports app: buildings, workers, reports, issues and checklists on a big screen.

The page runs entirely in the browser. It connects to the cleaning company's own cloud project and signs in with the
manager's account; it has no server and stores no customer data. Access is decided by the security rules of each
company's cloud.
